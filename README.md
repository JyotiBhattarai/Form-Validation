# Form-Validation
I built this project as part of my learning journey with HTML, CSS, and JavaScript. It's a simple registration form with proper input validation, designed to provide users with helpful feedback instead of leaving them with a broken or unclear form.
 ## What it does
The form checks everything before submitting:
- Username can only have letters, numbers and underscores and has to 
  start with a letter (between 3 to 20 characters)
- Email has to be in a proper format
- Contact number has to be exactly 10 digits
- Password needs at least 8 characters and one special character
- Confirm password has to match the password

## How to run it?
Download the files and open index.html in your browser. That's it.
