# Form Validation

I built this as part of my learning journey with HTML, CSS and JavaScript.It's a simple registration form with proper validation so users actually
get helpful feedback instead of just a broken form.

🔗 [Live Demo](https://JyotiBhattarai.github.io/Form-Validation)

## What it does

The form checks everything before submitting:
- Username can only have letters, numbers and underscores and has to start with a letter (between 3 to 20 characters)
- Email has to be in a proper format
- Contact number has to be exactly 10 digits
- Password needs at least 8 characters and one special character
- Confirm password has to match the password
- Errors show up as soon as you leave a field, not just on submit
- Password fields have a show and hide toggle

## How to run it

Download the files and open index.html in your browser. That's it.
